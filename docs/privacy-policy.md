# Política de Privacidade — SuperLista

Última atualização: [data]

O SuperLista é um aplicativo de lista de compras que funciona totalmente no seu aparelho.

## Dados
- Todas as suas listas, itens, preços, metas e histórico ficam armazenados **apenas no dispositivo**.
- Nada é enviado para servidores, coletado ou compartilhado com terceiros.
- O app não tem contas de usuário, não exibe anúncios e não usa rastreamento ou análise de uso.
- O app funciona sem conexão com a internet.

## Permissões
- **Câmera**: usada somente para ler códigos de barras, localmente no aparelho. As imagens não são gravadas nem enviadas.

## Como apagar seus dados
- Abra **Ajustes > Limpar todos os dados** no app, ou
- desinstale o aplicativo (todos os dados locais são removidos).
